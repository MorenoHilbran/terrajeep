# Terra Jeep Adventures

Premium Mount Batur adventure website — Jeep Tours & Trekking experiences based in Bali, Indonesia.

**Live site:** [terrajeepadventures.com](https://terrajeepadventures.com)

---

## Tech Stack

| Tool | Version |
|---|---|
| Next.js | 16 |
| React | 19 |
| TypeScript | 5 |
| Tailwind CSS | 3 |
| Swiper | 14 |
| React Icons | 5 |

---

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

> If you encounter dependency errors, run: `npm install --legacy-peer-deps`

---

## Project Structure

```
terra-adventure/
├── app/
│   ├── components/       # Page sections (Navbar, Hero, About, etc.)
│   ├── globals.css       # Global styles
│   ├── layout.tsx        # Root layout & SEO metadata
│   └── page.tsx          # Homepage entry point
├── public/
│   └── images/           # Site images (jeep-1 to jeep-8)
├── next.config.js
├── tailwind.config.js
├── tsconfig.json
└── package.json
```
